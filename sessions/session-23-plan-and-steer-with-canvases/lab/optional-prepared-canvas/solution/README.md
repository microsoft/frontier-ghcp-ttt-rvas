# Reference Solution

This directory contains an export of one acceptable reviewed canvas state and its evidence record. It shows the expected result after live work with GitHub Copilot.

## Files

| File | Purpose |
| --- | --- |
| `reviewed-release-state.json` | Export of the final shared canvas state |
| `evidence-record.md` | Completed live review and ownership record |

## Provenance and dependency decision

The teaching pattern was adapted from an internal release-readiness demonstration and the repository's Session 08 safety pattern. The inspected reference extension had no top-level license or notice that authorized copying its implementation. No source code was copied.

The files contain no secret or production data. They are reference exports and cannot replace live canvas work. Learners must use GitHub Copilot and an approved prepared canvas that implements `lab/starter/canvas-contract.md`.
