## Required fields

| Field | Why it is needed |

| Parent objective | Keeps the outcome visible |
| Issue number and title | Connects the canvas to GitHub |
| GitHub state | Shows the source-system state |
| Planning status | Shows the team's current planning view |
| Owner or gap | Makes responsibility visible |
| Dependency | Shows blocked sequencing |
| Risk | Records delivery concern |
| Decision | Records an approved change |
| Next action | Shows what happens next |

## Allowed actions

- Refresh approved GitHub issue data.
- Change planning status.
- Record a decision.
- Add or update a risk.
- Summarize current state.

## Prohibited actions

- Close or reopen GitHub issues.
- Change assignees.
- Publish messages or reports.
- Access another repository.
