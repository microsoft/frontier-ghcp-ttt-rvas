# Session M7-01: Work effectively in the GitHub Copilot app

**Module:** Product and Delivery Teams

**Difficulty:** Beginner

**Prerequisites:** A GitHub account with GitHub Copilot access

**Duration:** 3 hours (1 hour trainer content + 2 hours lab)

## Overview

Start the **Delivery Decision Studio** path by comparing answers with and without
repository context. Save what you learn in an initiative context brief. You check
context usage, request an independent critique, and test whether a fresh session
can use the brief without the original chat.

The fictional **Service Request Portal** is the shared scenario. You can use
sanitized work from your own team instead.

> [!IMPORTANT]
> **The GitHub Copilot app is required.** Fix access and client problems before
> the lab.

## Learning outcomes

Learners can:

1. Find and use Chats, Projects, My work, Search, Automations, and Customize.
2. Choose Interactive, Plan, or Autopilot mode for a task with a defined scope.
3. Add files with `@`, reference issues with `#`, and open commands with `/`.
4. Choose repository, issue, file, or uploaded-document context for a question.
5. Inspect the skills, agents, MCP servers, plugins, and canvases available to them.
6. Explain the difference between an MCP connection and a plugin package.
7. Check context usage and decide whether to compact or start fresh.
8. Review and revise a proposed Markdown change.
9. Update a context brief when new source information arrives.
10. Request an independent critique before sharing the brief.
