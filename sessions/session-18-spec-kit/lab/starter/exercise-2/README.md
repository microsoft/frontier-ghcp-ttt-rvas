# Exercise 2 Starter Kit

This starter kit contains the starting files for Exercise 2: "Specification Flow — 9 Phases."

## Contents

- `feature-request.md` — The feature to specify
- `problem-statement.md` — Problem analysis
- `.github/skills/` — Agent skills available
- `.specify/` (skeleton) — Structure for 9 phases

## Your task

1. Read the feature request
2. Fill in the Constitution phase manually
3. Use Copilot to suggest each subsequent phase
4. Document how the specification evolves as you clarify
5. Generate code and verify convergence

## What to practice

The 9-phase lifecycle is iterative. As you clarify Phase 3, you will often refine the specification in Phase 2 and the plan in Phase 4. Document those changes.

## Time: 30 minutes

Start by reading `feature-request.md`.
