# Exercise 3 Starter Kit

This starter kit contains the starting files for Exercise 3: "Governance & Risk."

## Contents

- `setup.sh` — Installation script (check for version pinning)
- `governance/` — Policy templates
- `.specify/` — Specification with exclusion patterns
- `test-fallback/` — Simulation environment for no-Copilot scenario

## Your task

1. Review the `setup.sh` script and verify version pinning
2. Generate `uv.lock` to lock all dependencies
3. Simulate Copilot unavailability and test fallback workflow
4. Apply content exclusion policy
5. Document team governance policies

## What to practice

Manage pre-1.0 tool risk with:

- **Pinned versions** — Lock exact versions
- **Lock files** — Reproduce the same setup across the team
- **Documented fallback** — Handle a tool or service outage
- **Content exclusion** — Don't expose sensitive data
