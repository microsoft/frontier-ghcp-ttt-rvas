# Exercise 1 Starter Kit

This starter kit contains the starting files for Exercise 1: "Specification First."

## Contents

- `problem-statement.md` — The feature requirement
- `.specify.yml` (skeleton) — Specification configuration
- `.github/skills/` — Created in the target project by `specify init`
- `src/` — Where you'll generate code

## Your task

1. Read the problem statement
2. Run `specify init user-api --integration copilot --integration-options="--skills"`
3. Use Copilot to complete the specification phases
4. Generate code that follows the specification
5. Run `specify check` to verify compliance

## Time: 30 minutes

Start by reading `problem-statement.md`.
