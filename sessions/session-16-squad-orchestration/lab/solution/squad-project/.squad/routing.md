# Routing Rules

| Work | Owner | Required output |
| --- | --- | --- |
| Clarify or assign Issue 001 | Lead | Assignment with files, non-goals, tests, and reviewer |
| Change request validation | Backend | Bounded source diff and result packet |
| Add or run focused tests | Tester | Test diff, command, and result |
| Approve, request changes, or pause | Lead | Review record |
| Update durable decisions | Scribe | Accepted decision with evidence and date |

No role may route new implementation work until the lead accepts the issue scope.
