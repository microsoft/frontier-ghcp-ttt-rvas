# Team

| Role | Purpose | Write boundary |
| --- | --- | --- |
| Lead | Assign work and make the final review decision | Assignment and review records |
| Backend | Implement Issue 001 | `src/routes/api.js` |
| Tester | Add focused tests and report the result | `tests/api.test.js` |
| Scribe | Maintain the durable decision record | `.squad/decisions.md` |

The team stops when ownership overlaps, scope grows beyond Issue 001, a test fails,
or the approved tool or data boundary changes.
