# Session 16: Brady's Squad: Human-Led AI Teams

**Module:** Specification-Driven Frameworks

**Difficulty:** Advanced

**Prerequisites:** Sessions 01–07 and 09–12
**Duration:** 3 hours (1 hour trainer content, 2 hours lab)

## Overview

This elective uses Brady's Squad to teach bounded roles, routing, durable
decisions, and review. The lab carries one input-validation issue from assignment
through tests and lead review. Learners can use the approved live path or the
supplied tabletop route.

## Learning outcomes

- Define a coordinator, specialized roles, and clear charters.
- Design shared decision records and role-specific history.
- Route independent work without overlapping ownership.
- Use GitHub Issues as reviewable work contracts.
- Decide when orchestration is worth its cost.

## Required access

For the live route, learners need **Node.js 20 or later**, Git, a GitHub training
repository, GitHub Copilot in the selected coding environment, and an approved
Squad installation. The lab includes a tabletop route when the orchestration tool,
repository integration, or network path is unavailable.

## Deliverable

Submit one review packet for the input-validation issue. It must include the
assignment, bounded implementation, test evidence, lead decision, and the durable
decision record. The reference solution includes both a `.squad/` result and a
tabletop equivalent.
