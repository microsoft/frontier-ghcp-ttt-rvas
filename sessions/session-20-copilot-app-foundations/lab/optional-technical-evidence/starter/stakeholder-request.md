# Stakeholder Request

**From:** Service operations lead  
**Requested outcome:** Reduce requests that miss an agreed response date.

Coordinators need to set a due date while triaging a request. The requester should see that date. Coordinators also want a reminder before the due date so they can act before a request becomes overdue.

For the first release:

- allow one due date per request;
- show it to the requester and coordinator;
- send one reminder 24 hours before the due date;
- avoid reminders for resolved requests.

Please keep the first release simple. Recurring reminders, service-level calculations, calendar integration, and manager escalation can come later.

The operations team expects the change in the next monthly release, but it should not bypass accessibility or release checks.
