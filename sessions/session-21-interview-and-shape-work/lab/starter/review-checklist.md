# Readiness Review Checklist

## GitHub Copilot evidence

- [ ] GitHub Copilot access passed preflight.
- [ ] The decision-tree interview ran with GitHub Copilot.
- [ ] The saved interview record shows recommendations, owner answers, and reasons.
- [ ] A person checked the Copilot drafts against the confirmed decisions.

## Decision brief

- [ ] The request is copied without silently changing its meaning.
- [ ] The affected user and current problem are specific.
- [ ] Scope and non-goals do not conflict.
- [ ] Constraints name their evidence or owner.
- [ ] Success can be observed.
- [ ] Failure cases state expected behavior.
- [ ] Decisions include reasons and owners.
- [ ] Open questions have owners and due points.
- [ ] The request owner recorded an approval decision.

## Work item

- [ ] The title states an outcome, not a broad initiative.
- [ ] The user statement matches the approved brief.
- [ ] Acceptance criteria are independently observable.
- [ ] At least one criterion covers a permission, failure, or unsupported state.
- [ ] Non-goals prevent obvious scope expansion.
- [ ] Dependencies and risks have owners.
- [ ] The definition of done includes validation evidence and human approval.
- [ ] The delivery owner, reviewer, and approver are named.

## Review result

Choose one:

- [ ] **Ready:** enter sprint planning.
- [ ] **Revise:** update the items listed below.
- [ ] **Blocked:** resolve the missing decision, fact, owner, or approval.
