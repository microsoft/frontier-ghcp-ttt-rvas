# Session m2-02: Agent mode in the IDE

**Module:** Copilot in Practice
**Difficulty:** Intermediate
**Prerequisites:** Sessions m1-01 to m1-03, m2-01
**Duration:** 3 hours (1 hr trainer content + 2 hr lab)

## Overview

Use agent mode for multi-step work with clear limits in an IDE. Learners build and
extend one Todo API. They compare Ask and Agent mode on the same feature, redirect
a multi-file change, and decide whether to accept, revise, or stop.

## Learning outcomes

- Explain the difference between assistant and agent workflows
- Use agent mode in VS Code for multi-step, multi-file tasks
- Use the agent loop: plan, act, observe, review, and revise
- Know when to use agent mode, Chat, or inline suggestions
- Use TODO code actions to bridge IDE and cloud agent workflows
- Review plans, diffs, commands, and test output at each checkpoint
