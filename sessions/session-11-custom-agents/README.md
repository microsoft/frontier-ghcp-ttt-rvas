# Session 11 — Custom Agents & Agent Profiles

**Module:** Agentic Workflows
**Difficulty:** Advanced
**Prerequisites:** Sessions 01–07, 10
**Duration:** 3 hours (1 hour trainer content + 2 hours lab)

## Overview

Custom agents define narrow roles in Markdown that teams can review. This session uses `.github/agents/` artifacts with limited tools, validation evidence, human review, and a manual fallback.

## Learning outcomes

- Create a focused agent profile.
- Define agent-specific tools, MCP dependencies, and stop conditions.
- Verify supported behavior on an approved Copilot surface.
- Choose between instructions, custom agents, skills, and MCP.
- Assign an owner to shared profiles.
