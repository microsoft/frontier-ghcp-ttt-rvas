# Session 14 — Infrastructure as Code with Copilot

**Module:** DevOps & Infrastructure with Copilot
**Difficulty:** Advanced
**Prerequisites:** Sessions 01–05, 13
**Duration:** 3 hours (1 hour trainer content + 2 hours lab)

## Overview

Use Copilot to draft, refactor, validate, and review Terraform and Bicep. The course focuses on modular definitions, security review, approved documentation context, and native validation before any cloud change.

## Learning outcomes

- Generate Terraform and Bicep with agent mode.
- Use Copilot Spaces as approved IaC context.
- Find and fix security problems in generated IaC.
- Validate infrastructure definitions with native tools.
