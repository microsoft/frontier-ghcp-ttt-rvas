# SKILL.md template

Use a small procedure that the team can review. Replace every placeholder with a repository fact.

````markdown
# Skill name
## When to use
Name the task, paths, and tasks that do not match.
## Preconditions
State data, permissions, and review requirements.
## Procedure
1. Read relevant source and tests.
2. Make the smallest permitted change.
3. Run the verified check.
4. Request review.
## Validation
Name the test, manual check, or review evidence.
## Anti-patterns
- Do not exceed the stated scope.
- Do not add dependencies or external access without approval.
## Fallback
State the manual procedure.
## Maintenance
Name the owner and review trigger.
````
