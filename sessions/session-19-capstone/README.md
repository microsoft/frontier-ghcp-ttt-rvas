# Session 19 — End-to-End Capstone Project

**Module:** Advanced Topics & Capstone

**Difficulty:** Advanced

**Prerequisites:** Sessions 01–12 and 17–18; Session 16 is optional
**Duration:** 3 hours (1 hour trainer content, 2 hours lab)

## Overview

The capstone delivers one bounded, handoff-ready feature change. Learners take a Session 18 specification through issue writing, an approved implementation path, focused checks, governance review, and a clear next action. The lab does not require a complete application or every Copilot surface.

## Learning outcomes

- Choose an implementation path within policy and budget limits.
- Turn one specification into a scoped issue and implementation plan.
- Produce test or manual-review evidence.
- Record the governance decision, deferred work, and next safe action.
