# Session 15 — CI/CD Debugging & Agentic Remediation

**Module:** DevOps & Infrastructure with Copilot

**Difficulty:** Advanced

**Prerequisites:** Sessions 01–05 and 13
**Duration:** 3 hours (1 hour trainer content, 2 hours lab)

## Overview

Use synthetic logs and a deliberately vulnerable training app to practice CI/CD diagnosis and remediation review. If the customer environment presents an approved **Assign to Copilot** route, learners review its proposed changes under the customer approval process. This session does not assume that route is enabled.

## Learning outcomes

- Diagnose pipeline failures from logs and workflow context.
- Review security findings and prepare a safe patch.
- Use an approved remediation route or the manual fallback.
- Validate changes with tests, scans, and human review before merge.
