# Course Safety Baseline

Use this checklist before any hands-on session:

1. Use the training repository and synthetic data.
2. Check the current GitHub docs and your organization's rules.
3. Check that learners have the tools and access they need.
4. Name the reviewer and the tests or checks the lab will use.
5. Set a usage limit for metered or automated work.

## When access is unavailable

Stop the learner lab. Fix access before continuing.

Prepared screenshots or captured output may keep a trainer demonstration moving.
They do not replace hands-on learner work.
