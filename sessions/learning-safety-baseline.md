# Course Safety Baseline

Use this checklist before any hands-on session:

1. Use an approved repository or sandbox and synthetic data.
2. Check the current GitHub documentation and customer policy for the feature you plan to use.
3. Confirm the permitted tools, access, and human reviewer.
4. Define the checks that show the work is safe to hand over.
5. Set a customer-owned stop condition for any metered or automated work.

## When access is unavailable

Use the supplied starter files and complete the exercise manually. Record the proposed change, the evidence you would review, and the human decision. Do not enable unapproved tools, use restricted data, or bypass customer policy.
