# Repository sandbox examples

These examples are for review, not installation. The required live comparison
uses the separate pinned `community-interview/` snapshot and the local Session m7-02
skill. Deliver skills only through the training project's `.github/skills/`.

```markdown
# Focused Test Addition
## When to use
Adding a regression test for a repository utility.
## Procedure
1. Reproduce the failure with a focused test.
2. Make the smallest change that meets the criteria.
3. Run the targeted test command.
4. Request repository review.
## Access failure
Stop the lab.
```

```markdown
# API Documentation Update
## When to use
A repository API contract changes.
## Procedure
1. Compare implementation, tests, and documentation.
2. Update examples and error cases.
3. Ask a reviewer to confirm the public contract.
## Access failure
Stop the lab.
```

Review scope, tools, data, validation, owner, maintenance, source, and license before adapting either example.
