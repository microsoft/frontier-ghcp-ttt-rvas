These files are unchanged snapshots. Check them with `sha256sum -c SHA256SUMS`
from this directory. On macOS, use `shasum -a 256 -c SHA256SUMS`.
Read both files before copying them into the training workspace.

`grill-me` is a user-invoked entry point and needs `grilling`. The dependency
interviews the user in rounds and may dispatch a subagent to look up facts.
There are no bundled scripts. Restrict the run to supplied synthetic files and
agree a usage limit. The skill does not grant tool or network permissions.

The lab requires neither a marketplace installer nor live downloads. Keep the
license beside the copied skill directories. Do not install these skills
globally or replace the snapshot with a mutable `main` revision during delivery.

**Maintenance owner:** training maintainers. Review a new pin when changing this
exercise. A checksum mismatch or missing dependency stops the lab.
