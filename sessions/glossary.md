# Glossary

Use this glossary when a product term appears before its full explanation. Session
links point to the first focused treatment, not every place where the term appears.

## Agent mode

An IDE workflow where Copilot can plan, edit files, run tools, and respond to
results. See [Session m2-02](session-m2-02-agent-mode-ide/README.md).

## Agent skill

A reusable `SKILL.md` package that gives an agent task-specific instructions and
supporting resources. See [Session m3-05](session-m3-05-agent-skills-ecosystem/README.md).

## Automation

A scheduled or event-driven Copilot task with defined tools, evidence, and review
rules. See [Session m7-06](session-m7-06-automate-delivery-follow-up/README.md).

## Canvas

An interactive Copilot App surface with visible state and actions shared by people
and agents. See [Session m3-01](session-m3-01-copilot-app-canvases/README.md) and
[Session m7-04](session-m7-04-plan-and-steer-with-canvases/README.md).

## Cloud agent

An asynchronous Copilot agent that works in a GitHub-hosted environment and
returns changes for human review. See [Session m3-02](session-m3-02-cloud-agent/README.md).

## Copilot App

GitHub's desktop application for agent sessions, projects, parallel work, and
review. See [Session m7-01](session-m7-01-copilot-app-foundations/README.md) and
[Session m2-05](session-m2-05-copilot-app-for-developers/README.md).

## Custom agent

A specialized agent profile with its own instructions, tools, and access
boundaries. See [Session m3-04](session-m3-04-custom-agents/README.md).

## Custom instructions

Repository, path, organization, or personal guidance that shapes how Copilot works
with a codebase. See [Session m2-03](session-m2-03-spaces-and-context/README.md).

## GitHub MCP server

The Model Context Protocol server that exposes approved GitHub reads and writes to
Copilot. See [Session m3-03](session-m3-03-mcp-servers/README.md) and
[Session m7-03](session-m7-03-plan-work-with-github-issues/README.md).

## Human gate

A required review or approval before an agent can continue or its work can be
accepted. See [Session m6-02](session-m6-02-capstone/README.md).

## Model Context Protocol (MCP)

A standard interface for connecting an agent to external tools and data. See
[Session m3-03](session-m3-03-mcp-servers/README.md).

## Pull request readiness

The point where scope, tests, review evidence, and remaining risks are clear enough
for a human pull request decision. See
[Session m2-05](session-m2-05-copilot-app-for-developers/README.md).

## RPI

The HVE Research, Plan, Implement, Review, and Follow-up delivery loop. See
[Session m5-03](session-m5-03-hve-core-challenge/README.md).

## Space

A curated set of repositories and other context used to ground Copilot responses.
See [Session m2-03](session-m2-03-spaces-and-context/README.md).

## Specification-driven development

A workflow that reviews requirements and planning artifacts before implementation,
then keeps them aligned with code and tests. See [Session m5-02](session-m5-02-spec-kit/README.md).
