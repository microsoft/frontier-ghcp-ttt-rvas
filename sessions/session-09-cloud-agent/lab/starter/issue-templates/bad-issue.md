# Example: Bad Issue

## Fix the API

The API has problems. It should validate input, handle errors better, and use cleaner code.

Please look at it and make improvements.

---

**Why this fails:**

| Problem                     | Impact                                                          |
| --------------------------- | --------------------------------------------------------------- |
| Vague title ("Fix the API") | Agent doesn't know which endpoint or what kind of fix           |
| No specific requirements    | Agent will guess what "validate stuff" means                    |
| No acceptance criteria      | Agent can't verify when it's done                               |
| Multiple unrelated asks     | Validation, error handling, and cleanup make the task too broad |
| No file references          | Agent has to search the entire codebase                         |
| "Make improvements"         | Subjective; the agent cannot tell when it is done               |
| No constraints              | Agent might add unnecessary dependencies or refactor everything |
