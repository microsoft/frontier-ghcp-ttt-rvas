# Starter files

Use these files with the live GitHub issues and the reviewed Session m7-05 parent
result.

| File | Purpose |
| --- | --- |
| `automation-definition-template.md` | Defines the automation's inputs, output, and limits |
| `approved-input-change.md` | Describes the reviewed issue update between runs |
| `stakeholder-update-template.md` | Holds the stakeholder-ready draft |

Do not copy platform run state into new forms. Use the Automations surface for run
status, tool calls, and output.

**GitHub Copilot and GitHub MCP access are required.** Fix access before using
these files.
