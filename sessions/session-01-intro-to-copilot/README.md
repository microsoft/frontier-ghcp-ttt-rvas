# Session 01 — Introduction to Copilot

## Overview

Start with the engineering loop: define a small task, inspect the proposal, run checks, and have a person review the result. Use Enterprise Cloud as the governance baseline. Before delivery, check the current GitHub documentation and the customer administrator policy.

## Learning outcomes

- Explain where an assistant fits in a human-reviewed development workflow.
- Run an access, data, and metered-work preflight before a live exercise.
- Define a bounded task, inspect the result, and validate it with tests or review.
- Complete the exercise manually when access is unavailable.
