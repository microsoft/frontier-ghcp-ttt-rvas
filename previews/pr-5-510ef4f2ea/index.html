    Module 1 — Copilot Fundamentals

    M1 Beginner 3h
    Introduction to GitHub Copilot
    What Copilot is, how the LLM works, plan tiers, privacy, and getting it running in the IDE for the first time.
    Open session 01
    M1 Beginner 3h
    Copilot Chat & Inline Suggestions
    Mastering the chat interface, slash commands, inline completions, and Next Edit Suggestions across all IDE surfaces.
    Open session 02
    M1 Beginner 3h
    Prompt Engineering Fundamentals
    How to construct prompts that reliably produce quality output — context, specificity, iteration, and custom instructions.
    Open session 03

    Module 2 — Copilot in Practice

    M2 Intermediate 3h
    GitHub Copilot CLI & App
    Using standalone Copilot CLI for terminal work, with Copilot App positioned alongside the VS Code hands-on baseline.
    Open session 04
    M2 Intermediate 3h
    Agent Mode in the IDE
    Autonomous multi-step tasks: Copilot reads files, runs commands, and iterates on errors inside VS Code.
    Open session 05
    M2 Intermediate 3h
    Copilot Spaces & Context Management
    Curated context sets, repository indexing, and managing what Copilot knows to improve output quality at scale.
    Open session 06
    M2 Intermediate 3h
    Copilot for Code Review & PRs
    AI-powered pull request reviews, automated summaries, issue-to-PR workflows, and Copilot Autofix in action.
    Open session 07
    M2 Advanced 3h
    Migrate a Legacy Java Service to Modern .NET
    Map the behavior of a legacy Java service, port it to modern .NET, and verify compatibility with focused tests.
    Open session 26
    M2 Intermediate 3h
    Repair and Refactor a Broken Python Application
    Repair a broken Python application, stabilize its tests, and refactor the code without changing required behavior.
    Open session 27

    Module 3 — Agentic Workflows

    M3 Advanced 3h
    Copilot App, Plugins & Canvas Extensions
    Use Copilot App customization and build a shared canvas with bounded state, actions, and review evidence.
    Open session 08
    M3 Advanced 3h
    Copilot Cloud Agent
    Assign issues to Copilot's cloud agent — it creates a branch, writes the code, runs tests, and opens a PR autonomously.
    Open session 09
    M3 Advanced 3h
    MCP Servers & Custom Tool Integration
    Model Context Protocol: giving Copilot access to external tools, APIs, and data sources through standardized server interfaces.
    Open session 10
    M3 Advanced 3h
    Custom Agents & Agent Profiles
    Building purpose-built agents with custom instructions, tool restrictions, and persona definitions for specific team workflows.
    Open session 11
    M3 Advanced 3h
    Agent Skills & the Copilot Ecosystem
    Packaging reusable domain knowledge as agent skills, discovering community skills, and orchestrating multi-agent workflows.
    Open session 12

    Module 4 — DevOps & Infrastructure

    M4 Intermediate 3h
    GitHub Actions & Workflow Generation
    Carrying one Node.js application through CI generation, deployment design, workflow repair, and custom-action validation with local evidence.
    Open session 13
    M4 Advanced 150m
    Infrastructure as Code with Copilot
    Using Copilot to author, connect, validate, and security-review Terraform modules, with Bicep as a trainer comparison and optional extension.
    Open session 14
    M4 Advanced 3h
    CI/CD Pipeline Debugging & Agentic Remediation
    Diagnosing pipeline failures from workflow evidence and local proof, including a staged failure and reviewed security remediation.
    Open session 15

    Module 5 — Specification-Driven Frameworks

    M5 Advanced 3h
    Brady's Squad: Human-Led AI Teams
    Use Brady's Squad to turn scoped work into persistent roles, decision records, and reviewable delivery evidence.
    Open session 16
    M5 Advanced 210m
    Spec Kit: Specification-Driven Development
    An end-to-end Spec Kit lab covering task-to-issue conversion, staged implementation, convergence, and living-spec evolution.
    Open session 18
    M5 Advanced 4h
    HVE Core: Evidence-Led Delivery with RPI
    Use HVE Research, Plan, Implement, Review, and Follow-up to move a bounded API feature from product intent to a human delivery decision.
    Open session 28

    Module 6 — Advanced Topics & Capstone

    M6 Advanced 3h
    Enterprise Governance, Policies & Analytics
    Content exclusions, policy configuration, seat management, usage analytics, and measuring AI adoption ROI at scale.
    Open session 17
    M6 Advanced 3h
    End-to-End Capstone Project
    A bounded integration scenario covering governance, specification, agentic delivery, review, and handover.
    Open session 19

    Module 7 — Product and Delivery Teams

    M7 Beginner 3h
    Work Effectively in the GitHub Copilot App
    Compare unscoped and grounded answers, revise a repository working brief when evidence changes, and verify it in a fresh session.
    Open session 20
    M7 Beginner 3h
    Interview Ideas and Shape Better Work
    Install a project interview skill, shape an unclear request, reopen affected decisions when constraints change, and verify the resulting brief.
    Open session 21
    M7 Intermediate 3h
    Plan Work with GitHub Issues and MCP
    Use GitHub MCP to inspect existing work, preview and create an issue hierarchy, then verify and correct it through fresh reads.
    Open session 22
    M7 Intermediate 3h
    Build and Use a Planning Canvas
    Create and simplify a planning canvas, detect drift from live GitHub state, and reconcile the visible planning projection.
    Open session 23
    M7 Intermediate 3h
    Orchestrate Agents and Workstreams
    Use the built-in orchestrate skill to supervise child sessions, redirect weak work, and consolidate only accepted evidence.
    Open session 24
    M7 Intermediate 3h
    Automate Delivery Follow-up and Connect Work Systems
    Create a manual draft-only Automation, compare two runs after an approved input change, and make a system-of-record decision.
    Open session 25

    Learning Tracks

    Copilot Essentials
    Sessions 01–03. Perfect for developers new to AI-assisted coding.
    Developer Productivity
    Sessions 01–07. Core capabilities for high-velocity development teams.
    Agentic Development
    Sessions 05, 09–12. Deep dive into autonomous AI agents and custom tooling.
    DevOps & Automation
    Sessions 07, 13–15. CI/CD, IaC, and automated security remediation.
    Enterprise Rollout
    Sessions 01–03, 06, 17. Governance, policies, and adoption at scale.
    Product and Delivery Teams
    Sessions 20–25. Use the Copilot app to interview, plan in GitHub, build canvases, orchestrate work, and automate follow-up.
    HVE Engineering
    Sessions 01–07, 10–11, and 28. Build the foundations for evidence-led HVE delivery.
    Full Mastery
    All sessions. The complete journey from zero to enterprise-ready Copilot delivery.
