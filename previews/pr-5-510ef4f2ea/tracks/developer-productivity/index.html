    Track: Developer Productivity¶

    Target Audience: Individual developers wanting to maximize daily productivity with Copilot Duration: 21 hours (7 sessions × 3 hrs) Difficulty: Beginner → Intermediate Recommended Delivery: 3 days (2–3 sessions per day)

    Description¶

    The core Copilot workflow track for developers who want to get the most out of Copilot every day. Covers all the surfaces and features a developer touches regularly — suggestions, Chat, prompting, CLI, agent mode, context management, and code review. This track transforms Copilot from "nice to have" into an indispensable part of the development workflow.

    Prerequisites¶

    • Working knowledge of at least one programming language
    • GitHub account with Copilot access
    • VS Code installed with GitHub Copilot extension
    • Basic Git proficiency
    • Familiarity with pull request workflows

    Sessions¶

    Order Session # Title Difficulty Duration
    1 01 Introduction to GitHub Copilot Beginner 3 hrs
    2 02 Copilot Chat & Inline Suggestions Beginner 3 hrs
    3 03 Prompt Engineering Fundamentals Beginner 3 hrs
    4 04 GitHub Copilot in the CLI Intermediate 3 hrs
    5 05 Agent Mode in the IDE Intermediate 3 hrs
    6 06 Copilot Spaces & Context Management Intermediate 3 hrs
    7 07 Copilot for Code Review & Pull Requests Intermediate 3 hrs

    Recommended Delivery Schedule¶

    3-Day Standard¶

    Day Sessions Focus
    Day 1 Sessions 01, 02, 03 Foundations: setup, Chat, prompting
    Day 2 Sessions 04, 05 Multi-surface: CLI + agent mode
    Day 3 Sessions 06, 07 Context management + code review

    4-Day Relaxed¶

    Day Sessions Focus
    Day 1 Sessions 01, 02 Setup and Chat workflows
    Day 2 Sessions 03, 04 Prompting + CLI
    Day 3 Sessions 05, 06 Agent mode + context
    Day 4 Session 07 Code review + wrap-up practice

    Learning Outcomes¶

    By completing this track, trainees will be able to:

    1. Use all Copilot surfaces fluently — inline, Chat, CLI, and agent mode
    2. Write effective prompts and apply context management strategies
    3. Configure Copilot Spaces and custom instructions for team workflows
    4. Use Copilot for PR summaries, code review, and merge conflict resolution
    5. Build a personal productivity workflow combining multiple Copilot surfaces
    6. Choose the right Copilot surface for any given task
    7. Set up project-level and personal context that improves Copilot's output quality

    Next Steps¶

    • Agentic Development — Move into Copilot App canvases, autonomous agents, MCP servers, and custom agents
    • DevOps & Automation — Apply Copilot to CI/CD pipelines, GitHub Actions, and Infrastructure as Code
    • Enterprise Rollout — Learn governance, policies, and rollout strategies for your organization
