    Track: Full Mastery¶

    Target Audience: Trainers delivering the complete curriculum Duration: 88 hours across 29 sessions Difficulty: Beginner → Advanced Recommended Delivery: 10-day intensive or 15-day standard

    Description¶

    Choose this track if you need to teach the full curriculum. It includes all 29 sessions, covering first-time setup, agentic delivery, DevOps automation, and supervision of agent work. You will prepare to teach technical teams as well as product and delivery teams that do not write code.

    Prerequisites¶

    • Strong software development background (multiple languages)
    • Familiarity with GitHub (repos, PRs, issues, Actions, org administration)
    • GitHub Copilot Enterprise Cloud access
    • Experience with CI/CD and at least one IaC tool (Terraform or Bicep)
    • Node.js or Python installed (for MCP server and agent development)
    • Docker for the Copilot SDK observability lab
    • Comfort with live coding, demos, and running technical workshops
    • Access to a cloud environment (Azure, AWS, or GCP) for infrastructure labs
    • GitHub Copilot app access for canvas and orchestration labs

    Learning outcomes¶

    After this track, you should be able to:

    1. Deliver any session using its trainer materials
    2. Customize delivery for developer, DevOps, enterprise, product, and delivery audiences
    3. Use the complete Copilot toolchain: inline, Chat, CLI, agent mode, Copilot App, canvases, cloud agent, Spaces, custom agents, MCP, skills
    4. Build canvas extensions, custom MCP servers, agent profiles, and agent skills
    5. Build a reliable TypeScript agent application with the GitHub Copilot SDK
    6. Generate and manage GitHub Actions, Terraform/Bicep IaC, and CI/CD pipelines with Copilot
    7. Apply a governed specification-driven development flow before implementation
    8. Orchestrate multi-agent teams with optional tools such as Squad
    9. Design and execute end-to-end agentic development workflows
    10. Assess trainee progress and adapt delivery based on audience needs
    11. Create a personal trainer delivery plan for their organization
    12. Teach non-developers to create briefs, issues, canvases, orchestrated work, and Automations with defined limits
    13. Teach HVE Research, Plan, Implement, Review, and Follow-up using linked phase results
    14. Teach developers to use isolated Copilot App sessions, independent critique, and test and review records for pull-request decisions

    Live app access is required for Session m2-05 and either Session m7-05 route. Prepared outputs support trainer explanation only. The schedule above uses Session m7-05's product route after Sessions m7-01 to m7-04. For a developer-only delivery, use its developer route after Session m2-05 instead; do not count the same session twice toward the 88-hour total. Session m3-05 requires live CLI skill loading.

    Next steps¶

    • Start with the track most relevant to your audience.
    • Combine sessions to match customer needs.
    • Update the curriculum based on your delivery experience.
    • Check feature status and update materials when Preview features reach GA.
