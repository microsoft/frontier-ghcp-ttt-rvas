## How to choose

- **New to Copilot:** Copilot Essentials (15 hrs)
- **Using Copilot daily:** Developer Productivity (27 hrs)
- **Ready for agents:** Agentic Development (42 hrs)
- **Pipelines and infrastructure:** DevOps & Automation (23 hrs 30 min)
- **Product or delivery role:** Product and Delivery Teams (18 hrs)
- **Adopting HVE Core:** HVE Engineering (31 hrs)
- **Teaching everything:** Full Mastery (88 hrs)

## Trainer notes

- Each track lists sessions in teaching order. Add or drop sessions to fit the customer.
- Most sessions run 3 hours. M5-03 has a 1-hour trainer segment and a 3-hour lab.
- **Live app access is required** for M2-05 and M7-05 (both Developer Productivity and Agentic Development). Prepared outputs don't replace the labs. M3-05 needs live CLI skill loading, and M2-05 also needs `/fork`, `/merge-to-parent`, and `/spar`.
- Set up CLI `/refine` before M1-03. Check local sandbox support for M2-01, a JavaScript language server for M3-04, and a Python one for M2-06.
- Each session's overview lists its own prerequisites. Open sessions from the [module list](../README.md).
