# Track: Full Mastery

**For:** trainers delivering the complete curriculum
**Time:** 88 hours, 29 sessions
**Delivery:** 15 days, up to 7 teaching hours a day

Teach every session, for technical teams and for product and delivery teams that don't write code.

## Before you start

- Strong software background and familiarity with GitHub (repos, PRs, issues, Actions, org administration)
- CI/CD experience and one IaC tool (Terraform or Bicep)
- Node.js 22.22.2 or later, Python 3.10 or later, and working JavaScript and Python language servers
- Docker for the M6-01 observability lab
- Copilot CLI and Copilot app access
- Cloud access is optional; the IaC lab runs locally
