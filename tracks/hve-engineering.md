# Track: HVE Engineering

**For:** developers, engineering leads, and trainers adopting HVE Core
**Time:** 31 hours, 10 sessions
**Delivery:** 5 days intensive or 10 days standard

Prepare for the HVE Core challenge. Learners build Copilot, context, review, MCP, and custom agent skills, then use them in M5-03 with HVE Research, Plan, Implement, Review, and Follow-up.

## Before you start

- Copilot access
- HVE Core installed as an extension or Copilot CLI plugin
- Node.js 22.22.2 or later, a JavaScript language server (M3-04), and CLI access with `/refine` (M1-03)
- Local sandbox support for M2-01
- Permission to download the supplied Node.js dependencies, or a prepared copy

## Phases

| Phase | Sessions | Focus | Time |
| --- | --- | --- | ---: |
| 1. Foundations | M1-01 to M1-03 | Chat, prompting, context | 9 hrs |
| 2. Guided engineering | M2-01 to M2-04 | CLI, agent mode, shared context, review | 12 hrs |
| 3. Agent integration | M3-03 to M3-04 | MCP tools, custom agents | 6 hrs |
| 4. HVE delivery | M5-03 | RPI challenge and human decision | 4 hrs |
