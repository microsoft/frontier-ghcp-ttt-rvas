# Track: HVE Engineering

**Target Audience:** Developers, engineering leads, and trainers adopting HVE Core

**Duration:** 31 hours across 10 sessions

**Difficulty:** Beginner to Advanced

**Recommended Delivery:** 5-day intensive or 10-day standard

## Description

Use this track to prepare for the HVE Core challenge. Start with daily Copilot
workflows, then practice selecting context, reviewing changes, and working with
MCP and custom agents. In Session M5-03, use those skills through HVE Research,
Plan, Implement, Review, and Follow-up.

## Prerequisites

- GitHub Copilot access in an environment that meets the organization's policy
- Node.js 22.22.2 or later and a working JavaScript language server for Session M3-04
- Standalone CLI access, including `/refine` for Session M1-03 and the commands and sandbox support in Session M2-01's preflight
- HVE Core installed through an approved extension or Copilot CLI plugin
- Permission to download the supplied Node.js dependencies or use a prepared copy

## Phases

| Phase | Sessions | Focus | Duration |
|---|---|---|---:|
| 1. Copilot foundations | M1-01 to M1-03 | Chat, prompting, context, and result checks | 9 hrs |

| 3. Agent integration | M3-03 to M3-04 | MCP tools and custom agents with defined scope | 6 hrs |
| 4. HVE delivery | M5-03 | Evidence-led RPI challenge and human decision | 4 hrs |

## Completion records

Keep these records as you work:

- Linked HVE Research, Plan, Implement, and Review files for the assigned feature
- Repository context, targeted instructions, and a custom reviewer, with records
  showing that Copilot used each customization
- Product Manager Advisor and Agile Coach outputs that shape or support the plan
- A tested API feature and container contract
- A human decision to approve, request changes, or pause
