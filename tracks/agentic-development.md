# Track: Agentic Development

**For:** teams adopting agentic workflows
**Time:** 42 hours, 14 sessions
**Delivery:** 5 to 6 days

Start with daily Copilot use, then learn to assign and review agent work with the Copilot app, cloud agent, MCP servers, custom agents, and skills. In M3-05 learners compare a local interview skill with pinned community skills and feed the accepted decisions into `/plan`.

## Before you start

- At least a year of software development, plus Git (branches, PRs, merging)
- Copilot Enterprise Cloud access
- Node.js 22 or later (CLI, live skills, MCP servers); Python 3.10 or later for the app labs
- Copilot app with `/rubber-duck`, `/orchestrate`, `/fork`, `/merge-to-parent`, and `/spar`
- `/refine` before M1-03 and local sandbox support for M2-01
- Node.js 22.22.2 or later and a working JavaScript language server for M3-04

M2-05, M7-05, and M3-05 need live app or CLI access. For M7-05, use the **developer route**. It doesn't need M7-01 to M7-04 or GitHub MCP.
