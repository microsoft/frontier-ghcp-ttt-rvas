# Track: Enterprise Rollout

**Target Audience:** Engineering managers, IT admins, Copilot champions, platform teams
**Duration:** 15 hours (5 sessions × 3 hrs)
**Difficulty:** Beginner → Advanced
**Recommended Delivery:** 2 days

---

## Description

Everything you need to plan, govern, and scale a Copilot rollout across an organization. This track covers Copilot fundamentals (so champions can demo and support), agent mode (the most impactful feature), and enterprise governance — policies, content exclusions, analytics, compliance, and rollout strategy. Designed for the people who make adoption happen: engineering leaders, IT administrators, and internal Copilot champions.

## Prerequisites

- Familiarity with GitHub organization administration (helpful but not required)
- Understanding of enterprise software governance concepts
- GitHub account with admin access to a GitHub organization (for governance labs)
- Basic programming knowledge (for demo credibility, not deep coding)

## Learning Outcomes

By completing this track, trainees will be able to:

1. Demonstrate core Copilot capabilities to stakeholders and team members
2. Explain Copilot's architecture, data handling, and privacy model
3. Configure organization-level Copilot policies, content exclusions, and MCP registries
4. Read and interpret Copilot usage analytics and adoption metrics
5. Design a phased enterprise rollout plan with measurable milestones
6. Address common enterprise concerns: security, IP, compliance, data residency
7. Build a "Copilot Champion" program for grassroots adoption
8. Use current official GitHub documentation to explain Enterprise Cloud capabilities and identify when a Business fallback is material
