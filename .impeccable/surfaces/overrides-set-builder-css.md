# Custom session sets

Mode: Operate for the builder; Read for the shared set.
Inherit the RVAP Technical Field Guide and shared header.

THESIS: A trainer chooses and orders sessions, then shares one focused page.

OWN-WORLD: Inherit the established RVAP white reading surfaces, navy headings,
Aptos/Outfit display stack, Aptos/Inter body stack, and blue actions.

STORY: Find sessions, arrange a delivery set, and give the group one shared page.

FORM: Extend the existing website using the user's specified reference
select-and-share flow. This is a pinned extension inside an established world,
not an open visual concept exercise. No concept roll ran; no seed is claimed.

FIRST VIEWPORT: A searchable catalog beside a set composer. Native checkboxes
keep selection clear; the composer shows the title, introduction, and delivery
order. On narrow screens, the composer sits above the catalog. The shared page
shows only the selected sessions in their chosen order.

INTERACTION: Selection survives filtering. Up/down buttons support keyboard
reordering. An explicit Create page action exposes a shareable link; editing
invalidates it. The current builder URL preserves the draft across reloads.
No accounts, backend storage, or confidential text.

QUALITY BAR: Follow the user-provided frontier-agentic-devops-rvas builder's
select-and-share flow within this site's RVAP controls. Use white/light surfaces
and blue selection, without adding a second visual identity. Keep copy concise.

SCOPE: Use the same catalog as the homepage. Keep all existing sessions and
material links. Add a set title and optional introduction, filtering, ordering,
shared reading, and edit links. Do not add prerequisites automatically or imply
that a selected subset replaces the curriculum's preparation requirements.

FINISH: Inspect desktop and mobile states, complete the finish review, and record
the shipped components in DESIGN.md and its sidecar.

Detector evidence: the active design hook reported no deterministic issues in
the builder/view templates or stylesheet. The finish review found a focused
Open page link with blue text on blue; its scoped focus rule now keeps white
text on Microsoft Blue. The focus handoff remains in place.

Primary set actions now keep white labels in every enabled state, with Microsoft
Blue at rest and Deep Navy on hover/press. This avoids switching white text onto
a light fill during focus transitions. Difficulty and module badges follow the
shared curriculum category palette requested by the user.
